# Sukun Café development guidance

- Treat `src/` as the editable source and `dist/` as generated output.
- Run `npm run check` and `npm run build` after changes.
- Preserve the current bilingual English/Arabic experience and RTL behavior.
- Preserve Sukun’s calm, minimal, warm and premium direction with its strong Arabic identity.
- Do not add generic AI-style cards, excessive gradients, decorative clutter or unrelated sections.
- Keep the existing ordering, customization, account, locations, events and responsive flows working unless a task explicitly changes them.
- This is currently a front-end portfolio prototype. Do not imply that demo authentication, payment, maps or order tracking are production services.
