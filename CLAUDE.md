# Sukun Café development guidance

- The editable website source is in `src/`; `dist/` is generated.
- Validate with `npm run check` and build with `npm run build`.
- Preserve the bilingual English/Arabic experience, including RTL behavior.
- Keep the visual direction calm, minimal, warm and premium with a strong Arabic identity.
- Avoid generic AI-style cards, excessive gradients, decorative clutter and unrelated sections.
- Preserve existing functionality and responsive behavior unless the task explicitly changes it.
- Authentication, payment, maps and order tracking are browser-based portfolio demonstrations, not production integrations.
