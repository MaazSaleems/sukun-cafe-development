# Sukun Café

Sukun Café is a responsive bilingual café website and ordering prototype designed for Kuwait. The experience combines a calm, minimal and warm visual identity with practical flows for browsing the menu, customizing products, ordering for pickup and following order status.

The project is a high-fidelity portfolio concept. Authentication, payment, maps and live café order management are demonstrated in the browser and are not connected to production services.

## Highlights

- English and Arabic layouts with RTL support
- Responsive navigation for desktop and mobile
- Searchable menu with category and vegetarian filters
- Product nutrition, customization and quick-add flows
- Customizable café combos
- Cart, pickup branch, timing and demo checkout flow
- Current-order status and expandable order history
- Locations, About and standalone Events pages
- Sukun’s custom branding, imagery and logo treatment

## Project structure

`dist/` is generated by the build command and intentionally excluded from Git.

## Requirements

- Node.js 20 or newer
- npm (included with Node.js)

The project has no third-party runtime or development dependencies.

## Run locally

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173). To use another port:

```bash
PORT=4173 npm run dev
```

## Validate and build

```bash
npm run check
npm run build
npm run preview
```

- `npm run check` validates JavaScript syntax and confirms referenced assets exist.
- `npm run build` recreates the deployable `dist/` folder from `src/`.
- `npm run preview` serves the generated build at `http://localhost:5173`.

## Demo data and privacy

- Account, cart and order information use browser `localStorage` only.
- Password input is validated for the prototype but is never saved.
- Checkout does not process or transmit payments.
- No API keys, passwords, tokens or private credentials are required by the project.

## Design direction

Sukun should continue to feel calm, minimal, warm and premium, with a clear Arabic identity. Preserve the restrained earth-toned palette, editorial typography, natural café imagery, generous spacing and bilingual experience. Avoid generic dashboard patterns, excessive gradients, decorative clutter and unrelated sections.
